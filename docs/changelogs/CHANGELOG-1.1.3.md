1.1.3 变更

承接 1.1.2，以修复为主，新增一个发射器功能。

新功能

- 发射器可以投掷手雷类物品：手雷、眩晕手雷、毒气手雷、窒息弹、蜂群弹、钉炸弹、狱火弹、燃烧瓶、信标手雷与钢球。
- 注意：子弹不会被发射器发射，仍按原版方式掉出物品。

修复

- 半自动光束枪（激光火铳、紫貂、华尔兹改）持有期间丢失视角摇晃。
- 只有真正的持续光束才按采矿光束渲染，半自动光束枪的光束不再异常停留。
- 子弹与爆炸命中伪装方块（Copycats+）时出现紫黑粒子、弹孔贴图缺失。
- mod 内生物在死亡动画期间仍会开火或挥击。
- mod 内生物的近战攻击可以穿墙。
- mod 内生物会攻击已经死亡的目标。
- 生物会主动攻击创造模式与旁观模式的玩家。
- 生物之间会内讧：同阵营子弹误伤同伴会触发报复链。
- 血液效果不再作用于车万女仆（女仆不会被本模组的效果溅血）。

女仆兼容

- 女仆被本模组枪械击中时不再产生受伤粒子（配置项 hide_gun_hit_particles，默认开启）。

技术说明

- 目标：Minecraft 1.21.1，NeoForge 21.1.x，Java 21。
- 依赖：GeckoLib、Framework、Curios。
- 移除了排查用的临时诊断日志。
