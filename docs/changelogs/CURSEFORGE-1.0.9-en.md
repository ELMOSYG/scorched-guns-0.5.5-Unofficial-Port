# Scorched Guns 1.0.9

**Minecraft 1.21.1 · NeoForge 21.1.150+**

## Physics structures (Sable): a few feel fixes

The previous version started on gunfire interacting with physics structures; this one tunes it. No new mechanism was
added, and one thing has to be said up front: **the explosion shockwave still does not work**, so a structure is only
moved by a shot or shell that hits it directly.

Three fixes:

- **Light structures are no longer immovable.** Sable scales its impulse by mass, so a single plank - which weighs
  almost nothing - got an impulse of almost nothing and appeared to ignore gunfire. Every hit now has a floor speed
  change (0.12 blocks/s), so light builds visibly shake and get pushed.
- **Shotguns no longer launch structures.** That floor is per hit, and a shotgun fires 8-10 pellets, so every pellet
  collected the full floor and the shove added up to ten times what was intended. The floor is now scaled by each
  pellet's share of the shot.
- **Firing while standing on a structure no longer throws you off it.** `onGround()` is false on a Sable sub-level, so
  firing downwards took the "aiming down while airborne" branch and got a 1.25x upward boost; a high-rate gun such as
  the Callwell lifted the player off the deck in a few shots. On a physics structure the upward component of recoil is
  now zero. Horizontal recoil is unchanged.

## Bayonet melee rework

The old attack was one constant-speed push forward and one constant-speed return, which read as mechanical. It is now
three phases:

```
wind-up  -> the whole gun tilts left 17.5 degrees while pulling back 0.375 blocks
drive    -> thrusts 0.408 blocks along the gun's own axis, rolling back through zero and slightly past
recovery -> eases back to rest
```

Details:

- The curves are sampled with Catmull-Rom, the same interpolation the hand-authored keyframes used, so the direction
  changes carry momentum instead of snapping.
- The push runs along the **gun's own** axis rather than world Z; after the tilt, that is what makes the motion flow.
- The arms are untouched - only the gun is transformed, so they keep their normal hold.
- It applies to **every gun, including addon guns**, and does not depend on any animation file.

> If you prefer the previous constant-speed motion, this can be reverted wholesale - just ask.

## Hit sounds restored to the original system

The headshot sound had been replaced with the mod's own `scguns:hit.hitmarker` (a 0.106 s click), which was hard to
tell apart from a critical hit. It is back to the 0.5.5 default:

| Event | Sound |
|---|---|
| Critical | `minecraft:entity.player.attack.crit` |
| Headshot | `minecraft:entity.player.attack.knockback` |

**If your `config/scguns-client.toml` was generated by an older build it still holds the old value** - existing config
files are not rewritten, so change it by hand.

Volume and pitch stay at 2.0 / 1.8: this mod's gunshots are long and loud (about 1 s on average, 3.8 s for a carbine),
so a vanilla-loudness hit sound is completely masked.
