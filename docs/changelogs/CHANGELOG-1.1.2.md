# 1.1.2

上一篇 `1.1.1coldfix` 的后续整理，内容以修复为主，没有新增玩法。

## 修复

### 子弹命中不再忽略弹丸体积
子弹的 `size` 以前只影响可视碰撞箱和撞方块，打实体时按“子弹中心点”的连线判定，所以 `size: 2` 的子弹擦着
实体边缘飞过却打不中。现在命中判定会把实体箱按子弹半径膨胀后再求交，粗子弹终于有粗子弹的手感
（`forlorn_hope` 这类自定义 size 的枪尤其明显）。

### 上一版的弹丸实体堆积修复
`1.1.1coldfix` 已修（弹丸不再写入存档、超出 125 块会被清扫），本版没有再次改动，只是沿用。

## 调整

- 附魔中文名按实际效果重定：音速弹、贯穿弹、重型弹、灵巧快手、金手指；删除了游戏内不存在的
  纵火狂条目。
- 移除构建产物中的临时诊断日志（弹丸清扫、穿甲补偿），正常游玩不再刷屏。

## 已知问题（上游设计，未改动）

- 换弹过程中按卸弹键（U）仍可能导致无限换弹且不消耗弹药，左轮类武器还会凭空生成弹壳。暂时规避方式：
  不要在换弹动画播放期间按 U。（这是原版 0.5.5 就存在的问题，未在本移植中改动。）
- 护甲穿透逻辑保持 1.20.1 上游的百分比模型，未做改动。

## 技术说明

- 目标版本：Minecraft 1.21.1 / NeoForge 21.1.x，Java 21。
- 依赖：GeckoLib、Framework、Curios。
