1.1.2 变更

接续 1.1.1coldfix，只有修复，没有新玩法。

修复

- 子弹命中不再忽略弹丸体积。之前 size 只影响可视碰撞箱和撞方块，打实体时按子弹中心点的连线判定，所以 size 为 2 的子弹擦边就穿过去；现在命中判定会把实体箱按子弹半径膨胀后再求交。
- 移除了构建中的临时诊断日志。

调整

- 附魔中文名按实际效果重新命名：音速弹、贯穿弹、重型弹、灵巧快手、金手指；同时删除了游戏内不存在的附魔条目。

已知问题（与上游一致，未改动）

- 换弹过程中按卸弹键 U 仍可能导致无限换弹且不消耗弹药，左轮类武器还会凭空生成弹壳。规避方式：不要在换弹动画播放期间按 U。
- 护甲穿透保持 1.20.1 上游的百分比模型。

技术要求

- Minecraft 1.21.1，NeoForge 21.1.x，Java 21。
- 依赖 GeckoLib、Framework、Curios。
