# Scorched Guns 1.0.9

**Minecraft 1.21.1 · NeoForge 21.1.150+**

## 一、物理结构（Sable）：几处手感微调

上一版开始处理枪械与物理结构的交互，这一版继续微调，**没有新增机制**。需要先说清楚：**爆炸冲击波依然不生效**，
所以结构仍然只有"被子弹/炮弹直接命中"才会动。

调的是这三处：

- **轻结构不再纹丝不动。** Sable 的冲量按质量缩放，一块单格木板的质量几乎为零，算出来的冲量也就几乎为零，
  于是枪打上去像打在空气里。现在给每次命中一个最小的速度变化（0.12 格/秒），轻结构会明显抖动、被推动。
- **霰弹枪不再把结构打飞。** 上面那个最小值的单位是"每次命中"，而霰弹一发是 8~10 颗弹丸，每颗都吃满最小值，
  叠加起来就是十倍推力。现在最小值按这颗弹丸在整发里的占比缩放。
- **站在结构上开枪不再起飞。** 站在 Sable 结构上时 `onGround()` 返回 false，朝下开枪会命中"在空中下压"
  分支，得到 1.25 倍垂直推力；高射速的枪（考威尔这一类）几发就把玩家顶离甲板。现在站在物理结构上时，
  后坐力的向上分量完全归零，水平后坐照常。

## 二、刺刀近战动作重做

原来的刺刀动作是匀速前推再匀速回收，看起来机械。现在是三段节奏：

```
蓄力 → 整体向左侧倾 17.5°，同时后拉 0.375 格
突刺 → 沿枪自身轴向刺出 0.408 格，翻转回正并略向右过冲
回收 → 平滑归位
```

几个细节：

- 曲线用 Catmull-Rom 采样，和手调关键帧的插值方式一致，转折处有惯性而不是硬拐。
- 位移沿**枪自身**的轴，不是世界 Z 轴；侧倾之后仍然朝枪口方向刺，动作才顺。
- 手臂不动 —— 只变换整把枪，手臂保持原本的持枪姿势。
- **对全部枪生效，包括附属模组的枪**，不依赖任何动画文件。

> 如果你更喜欢上一版的匀速动作，这一版可以整体回退，跟我说一声。

## 三、命中音效恢复原版

爆头音效之前被换成了模组自带的 `scguns:hit.hitmarker`（0.106 秒的点击声），听感和暴击几乎分不出来。
现在恢复成 0.5.5 的默认值：

| 事件 | 声音 |
|---|---|
| 暴击 | `minecraft:entity.player.attack.crit` |
| 爆头 | `minecraft:entity.player.attack.knockback` |

**如果你的 `config/scguns-client.toml` 是旧版本生成的，里面还留着旧值，需要手动改成上面两个**
（配置已经存在时不会自动重写）。

音量/音高保持 2.0 / 1.8：这模组的枪声又长又响（平均约 1 秒，卡宾 3.8 秒），命中音用原版音量会被完全盖住。
