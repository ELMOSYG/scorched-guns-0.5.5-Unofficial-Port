# Scorched Guns 0.5.5 · 1.21.1 / NeoForge 非官方移植

**移植版本 1.0.8** | 文件名 `scguns-1.0.8.jar`

这是把 **Scorched Guns 0.5.5**（原作 Minecraft 1.20.1 / Forge）搬到 **Minecraft 1.21.1 / NeoForge** 的非官方移植版。
由社区维护，非官方，与原作者的官方版本无关。

移植的目标是尽量贴近原作：全部枪械数据按上游 0.5.5 逐一核对，进度、袭击、战利品和生产线保持原样。

---

## 内容

| 项目 | 数量 |
|---|---|
| 枪械 | **一百四十余把**，全部带动画 |
| 枪械类型 | 13 种（手枪、冲锋枪、步枪、霰弹、狙击、机枪、重型、轨道、激光、等离子、电击、火焰喷射、特殊） |
| 进度 | **261** 项 |
| 袭击 | 11 场，每场有首领与随从 |
| 生产线 | 从**发电**（雷电电池、极性发电机）到**弹药与模具**（冲压机、研磨机），再到枪械本身 |

另有炮塔与战斗机械、外骨骼动力甲、专属附魔、蓝图系统与枪械工作台配方面板。

## 这个移植版做了什么

- **为其它移植版的附属模组做了兼容层**：很多枪械附属是针对别的 1.21.1 移植编译的，直接放进本体会出现配件不渲染、
  后坐与散布无效、暴击与伤害衰减被忽略、无法附魔等问题。这些都修好了。
- **三个会让存档或游戏不可用的问题**：把雷电电池接入别的模组电网会崩服并让存档无法加载；专用服务器上弹孔不显示；
  没装 Polymorph 时整个模组加载失败导致游戏起不来。
- **计数弹匣的视觉修正**：换弹时弹匣不再抽动，换完也不再闪回空仓位置。
- **原版没有做全的两件事**：自动光束与连发光束两种射击模式（数据里定义了却没注册）现在能用了；
  生物类型判断改为先问实体本身、再退到类型标签，穿僵尸头的训练假人也能吃亡灵加成。

## 注意

- 枪械的伤害、弹药与配件数据都可以用数据包改，本体不锁死。
- 与别的枪械模组同装时，武器工作台配方可能冲突；装了 Polymorph 可以在界面上选。
- 反馈问题时请带上 `latest.log` 和复现步骤，有截图更好。

## 给附属作者

本模组的 mod id 是 `scguns`，依赖声明里的兼容版本是 **1.5.0**（与移植版本号分开维护，专门给附属的
`versionRange` 用）。所以在附属的 `neoforge.mods.toml` 里写：

```toml
[[dependencies.yourmod]]
modId = "scguns"
type = "required"
versionRange = "[1.5.0,)"
```

Minecraft 1.21.1、NeoForge 21.1.150+。可用的公开 API 与数据格式沿用上游 0.5.5。
