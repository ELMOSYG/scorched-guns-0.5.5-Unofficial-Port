# 1.1.0 hotfix

**发布日期**：2026-11-12

## Raygun 开火卡顿

**现象**：只有 Raygun 一开火就卡，其它枪正常。

**原因**：`raygun.json` 里 `projectile.size` 被填成了 **100**。这个字段以前是死值 —— 上一版修好了碰撞箱刷新之后，它才真的生效，于是每一发子弹都带着 100×100 的碰撞箱，实体碰撞检测瞬间被打爆。`hullbreaker.json` 同样填了 100。

**修复**：两个数据分别改成 0.6 和 1.0；同时在 `ProjectileEntity` 里把 `size` 夹紧到 **0.05 ~ 4.0**，以后数据再写错也不会再出现这种卡顿。

## 说明：激光武器“关闭视角摇晃”不是 bug

激光类（Laser Musket、采矿激光）是光束武器，开火必须持续瞄准，看起来像没了摇晃；它们的数据里还写着 `hasCameraShake: false`，那是原作者有意关掉的后坐镜头抖动。Raygun 是普通自动手枪，摇晃正常。
