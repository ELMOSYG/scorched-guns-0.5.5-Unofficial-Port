# Scorched Guns 1.1.1

## 恶性 bug 警告（请先读这一段）

**逐发装填枪械在换弹过程中按“卸载弹药”会导致无限装弹。** 弹药被清空后装填流程仍在继续，
每 tick 从背包取走一发、弹匣却永远填不满，于是既吞掉背包里的全部弹药，又表现为换弹永不结束。

**Cowell 等转轮/逐发装填枪械还能借此刷弹壳。** 卸载与换弹交错时，弹壳产出被触发多次，
可以反复获得弹壳。

**规避办法：换弹动画期间不要按卸载键（默认 U）。** 这个缺陷来自上游 0.5.5 的换弹状态机
（同一份“是否在换弹”的状态被同步键与两个 NBT 键并行维护，且 `AmmoCount` 有多个写入者），
我们尝试过的几种补丁都会在别处引发新问题（换弹时长随机、打空后不再产壳），因此 1.1.1
**保持上游行为**，在这一版以警告形式告知，而不是带入新的不稳定改动。
详见 `docs/reload-system.md`。

## 修复

### 爆炸与方块破坏
- 火箭的爆炸半径从 7.0 改为 4.0，与 TNT 一致（原来单发火箭等同于约五倍 TNT 的破坏量）。
- 火箭爆炸重新填充 `getToBlow()` 集合，修复“火箭炸不坏方块”。
- 高爆榴弹（HE grenade round）补上缺失的爆炸对象，恢复对方块的破坏。

### 弹道与命中
- 弹丸实体在应用 `projectile.size` 后刷新碰撞箱，修复“改 size 也打不中”的问题。
- `projectile.size` 数据修正：141 把枪里 `1e-05`、`100.0` 这类异常值统一收进 0.05–4.0 区间。
- 近战命中包不再持有活的 `ItemStack`，修复换弹/瞄准时偶发的 `ConcurrentModificationException`。

### 界面与显示
- 改装配件界面不再重复应用配件修正（撞火枪托显示 1200 RPM 而实际 600 的问题）。
- 其他玩家的枪机（bolt）骨骼恢复正常显示（原逻辑只对自己渲染）。
- 头部的调试框（F3+B）不再为超大型实体（Sable 物理结构）绘制，缓解因此产生的掉帧。

### 兼容
- EMF（Entity Model Features）共存时不再重复绘制手臂；配置项 `suppressVanillaArmWithGun`、`emfSkipPlayerAnimationWithGun` 可调。
- 后坐力乘数取到 0 时回退为 1.0，避免第三方模组把后坐力整体抹平。

### 世界与结构
- 结构放置不再被 1.21 默认的 `APPLY_WATERLOGGING` 灌水（6 个结构 JSON + `CogChambers`）。
- `raid` 数据文件形状不符时跳过而不是抛异常刷栈。

### 性能
- 电击线圈的电弧粒子改为世界坐标，不再让客户端加载内部坐标指向的远处区块。
- 电弧粒子步长 0.15→0.6、点数上限 48，`sendParticles` 从占服务端 tick 的 82% 降到约四分之一。
- 电击线圈附近没有玩家时完全跳过目标搜索，避免为无人区域拉取区块。

### 游戏性
- 工作台制作出的枪械从空弹匣开始（此前缺 NBT 时被当作满匣）。
- 弹匣类枪械的“装填完成”包做幂等处理，修复多人游戏中换弹被结算两次。

## 已回退的尝试（不要重复）

1.1.0hotfix 到 1.1.1 之间曾尝试用 `ReloadState` 统一三套换弹状态，结果导致换弹动画提前重播、
换弹时长忽快忽慢；也试过在卸载包里加多层拦截与 `ScgunsUnloadedMag` 标记，结果造成打空后
换弹不再产壳。两批改动均已回退，备份在标签 `backup-reloadstate-20261115`。
