# Scorched Guns 1.1.1 (1.21.1 / NeoForge)

## 恶性 bug 警告（请先读这一段）

**在换弹动画期间按“卸载弹药”（默认 U）会让逐发装填枪械无限装弹，并且不消耗任何弹药。**
卸载把弹匣清零后，装填流程仍在继续，弹匣却始终填不满，于是换弹永远不结束；整个过程**不扣除背包里的
弹药**，等于无限子弹。

**Cowell 等转轮 / 逐发装填枪械还能借此凭空刷弹壳。** 卸载与换弹交错时弹壳产出被反复触发，
且没有任何对应的消耗，可以无限获得弹壳。

**规避办法：换弹动画期间不要按卸载键。** 服务器上建议用日志或权限管理监控该操作。

这个缺陷来自上游 0.5.5 的换弹状态机：同一份“是否在换弹”的状态由同步键与两个 NBT 键并行维护，
`AmmoCount` 又有多个写入者，卸载与装填会各自改写它。我们试过的几种补丁都会在别处引发新问题
（换弹时长随机、打空后不再产壳、切枪后状态残留），因此 1.1.1 **保持上游行为**并在此明确告知，
而不是带入新的不稳定改动。

## 修复

### 爆炸与方块破坏
- 火箭爆炸半径由 7.0 改为 4.0，与 TNT 一致（原先单发火箭的破坏量约为 TNT 的五倍）。
- 火箭爆炸重新填充 `getToBlow()` 集合，修复“火箭炸不坏方块”。
- 高爆榴弹补上缺失的爆炸对象，恢复对方块的破坏。

### 弹道与命中
- 弹丸实体应用 `projectile.size` 后会刷新碰撞箱，修复“改了 size 仍然打不中”。
- 弹丸 size 数据修正：141 把枪里 `1e-05`、`100.0` 之类的异常值统一收进 0.05–4.0。
- 近战命中包不再持有活的 `ItemStack`，修复换弹途中偶发的并发崩溃。

### 兼容
- 与 EMF（Entity Model Features）共存时不再重复绘制手臂；新增配置项
  `suppressVanillaArmWithGun`、`emfSkipPlayerAnimationWithGun`。
- 后坐力乘数取到 0 时回退为 1.0，避免第三方模组把后坐力整体抹平。

### 世界与结构
- 结构放置不再被 1.21 默认的 `APPLY_WATERLOGGING` 灌水（6 个结构定义 + `CogChambers`），
  海洋群系里的船体与潜艇内部保持干燥。

### 弹丸实体堆积
- 弹丸有了 128 格的飞行距离上限。模拟距离小于渲染距离时，两者之间的区域里的实体不会被 tick，
  原先的寿命判定因此永不推进，等离子与幽匿弹丸会停在那里并被实体雷达一直显示。128 格以外本来
  也打不到任何目标。
- 弹丸一旦进入“不会被 tick”的区域就立即销毁，不再停留在边缘。
- 服务端每 10 秒清理一次超出模拟距离的本模组弹丸，处理此前已经滞留的实体。
- 弹丸不再写入区块存档，区块卸载后不会留下孤儿实体。

### 性能
- 电击线圈的电弧粒子改用世界坐标，不再让客户端加载内部坐标指向的远处区块。
- 电弧粒子步长 0.15 → 0.6、点数上限 48，`sendParticles` 的开销降到原先约四分之一。
- 电击线圈附近没有玩家时跳过目标搜索，避免为无人区域拉取区块。

### 游戏性
- 工作台制作出的枪械从空弹匣开始（此前缺少 NBT 时会被当作满匣）。
- 弹匣类枪械的“装填完成”包做幂等处理，修复多人游戏里换弹被结算两次。

## 说明

- 版本号 `1.5.0+1.1.1`，文件为 `scguns-1.1.1.jar`。
- 仅支持 Minecraft 1.21.1 / NeoForge 21.1.x。
