# Scorched Guns 1.0.7.2

**Minecraft 1.21.1 · NeoForge 21.1.150+**

> 小版本。代码里的版本号仍是 1.0.7，jar 改名为 `1.0.7.2` 便于区分。

只改一件事：COG 骑士的冲锋。困难难度下，带齿轮锤的骑士一次冲锋能打掉铁套玩家约 19 点血（19.1 / 20），而且那次冲锋
**躲不掉**——它每一 tick 都在重新瞄准玩家并直接朝玩家方向设定速度，20 tick 内全程追踪，没有预备动作。

## 四个问题

| 问题 | 修法 |
|---|---|
| 一次冲锋会命中两次 | 20 tick 的冲锋对上 10 tick 的受击无敌帧，命中区间每 tick 都会被调用。加"每次冲锋只命中一次"的标志 |
| 全程追踪，无法躲避 | 改成 **6 tick 蓄力 + 6 tick 冲刺**：蓄力期站定、持续锁定；冲刺期沿锁定方向直冲，不再转向 |
| 伤害过高 | 冲锋最终伤害上限 **18**，按难度反算原始封顶（困难 ÷1.5） |
| 冲得太久、太慢 | 冲刺速度 0.8 → **1.15**，总时长 20 → **12** tick，实际冲刺距离约 10 格 |

另外蓄力期会**预判**玩家 5 tick 后的位置。这不是为了让冲锋更难躲，而是为了避免出现"对着原地冲、玩家慢慢走开"的滑稽画面：
现在只靠往一个方向平移会被预判命中，但看准 0.3 秒的蓄力窗口**变向或急停**就能躲开，冲完还有 4 秒冷却可以反打。

这解决了前期没有远程武器时只能绕着走的问题——现在至少能近战周旋。
