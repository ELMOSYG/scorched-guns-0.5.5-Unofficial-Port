# Scorched Guns 1.0.7

**Minecraft 1.21.1 · NeoForge 21.1.150+**

> 本版取代尚未发布的 1.0.6。守卫相关的改动占了大半，此外修掉了一个会**永久毁掉装备维修**的附魔问题。

---

## 一、枪械/护甲的战利品附魔错了（最严重）

### 枪拿到锋利、时运

`minecraft:enchant_randomly` 是唯一**不检查物品能否附魔**的附魔函数：只要不写 `options`，
它就从这个池子里随便挑一个——所以枪会随机带上锋利、时运等完全无关的附魔。

修法：枪的条目一律指向本 mod 的专属池 `#scguns:gun_random_loot`（15 个本 mod 附魔 + 耐久 + 经验修补）。

### 附带发现：上一轮的修复把护甲也改成了枪械池

上一轮修这个问题时，整张表里所有 `enchant_randomly` 都被改成了枪械池，
于是**头盔、胸甲、护腿、靴子、刺刀**会抽到"加速器""轻量"这类枪械附魔。

修法：按物品类型分流——在 `#scguns:guns` 里的用枪械池，其余回到原版 `#minecraft:on_random_loot`。
全表复核：枪 8 处用枪械池，护甲/其它 28 处用原版池，**错配 0 处**。

### 铁砧的附魔书通道也是全开的

`Item#isBookEnchantable` 原版对任何物品都返回 `true`，而移植版把非采矿枪直接交给它、
采矿枪更是无条件放行，所以**任何附魔书都能打在枪上**（包括"致密"这种重锤专属附魔）。

修法：逐条校验附魔书内容。
- 普通枪：只接受本 mod 附魔 + 耐久 + 经验修补
- 采矿枪：额外接受效率、精准采集、时运
- 致密等其它一律拒绝

附魔台本来就按每个附魔的 `supported_items` 过滤，只有上述通道有问题。

## 二、警卫村民（Guard Villagers）

### 生成时武器被瞬间替换

装备来源有两处：GV 自己的生成装备表（`entities/guard_armor`）和我们的代码装枪。
两者都写同一只手，谁后跑谁覆盖，玩家会看到守卫刚生成就换武器。

修法：装备只由数据表决定（新增配置 `guard_guns_from_config`，默认关闭），
我们覆盖 GV 的装备表，在主手池里加入 5 把低阶枪，权重 38%：

| 枪 | 权重 | 档位 | DPS |
|---|---|---|---|
| `longarm` | 3 | antique | 7.6 |
| `musket` | 2 | antique | 4.8 |
| `saketini` | 2 | frontier | 4.3 |
| `winnie_millend` | 2 | frontier | 15.0 |
| `pax` | 1 | frontier | 15.6 |

玩家交武器转职的守卫不走这张表，所以手上的剑不会被抢。

### 枪手 AI

| 问题 | 修法 |
|---|---|
| 看见就开枪（40 格外也打） | 新增开火距离门限，`min(枪的 idealAttackRange, guard_gun_max_range=20)` |
| 远处队友挡枪线被打中 | 队友检测从"前方 6 格框"改为**整条弹道的射线**，并加余弦阈值 `guard_friendly_fire_check_value=0.9` |
| 被挡住时每 tick 重试，原地抖 | 侧移后锁 10 tick 再试 |
| 装填 0 tick 完成（等于不装填） | 修掉提前设置 `reloading` 导致跳过计时初始化的写法；装填时长下限 4 tick |
| 装填时间不对 | 改用 `GunEnchantmentHelper.getRealReloadSpeed`，与玩家一致（装填类型 + 快速双手 + 配件） |
| 单发装填武器不适配 | `SINGLE_ITEM` 类型容量强制为 1 |
| 弹匣判定依赖 NBT | 改为按射击计数，战利品表给的枪也能正确换弹 |
| goal 重建导致装填从头开始 | 装填进度存到实体上；旧存档里的脏状态用版本戳一次性作废 |
| 持盾时不后退 | 举盾时站定射击，不再和 GV 的 `RaiseShieldGoal` 抢导航 |

### 持枪姿态

- 手臂改为**跟随头部俯仰/偏航**（照原版 `CROSSBOW_HOLD` 的写法），目标在上方/下方时枪口会跟着抬/压
- 蹲姿只在**换弹**时使用（`guard_gun_crouch_when_reloading`，默认开）；瞄准时站立
  - 踩过的坑：原版 `+0.4` 弧度那行是给"垂手"姿态用的，用在持枪姿态上会把枪口压进地板；改成反向又会朝天，最终**不做补偿**
