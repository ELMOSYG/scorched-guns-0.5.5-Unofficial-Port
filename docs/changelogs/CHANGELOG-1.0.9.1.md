# Scorched Guns 1.0.9.1

**Minecraft 1.21.1 · NeoForge 21.1.150+**

这是一次修正版，改动集中在附魔与配方界面上，另外把 1.0.9 里一处推力公式改回来。

## 一、附魔：不在标签里就附不上（包括铁砧）

`GunItem` 之前对自家附魔一律回答“可以”，于是铁砧和附魔书绕过了附魔自己的 `supported_items` 标签。

受影响最明显的是**一战附属（scgunsww1）**里的两把 400 RPM 机枪 —— **麦德森（Madsen）**和**MG 08/15**：
作者有意把这两把排除在 `#scguns:enchantable/trigger_finger` 之外，就是为了不让它们吃黄金指的射速加成，
但铁砧仍然能给它们打上，射速直接翻倍。

现在自家附魔和原版附魔一样，都走标签判断；铁砧那一侧再加一层拦截，非法组合直接没有产物，
而不是悄悄成功。**旧存档里已经打上的附魔不会被移除**，需要自己用砂轮或指令清掉。

## 二、附魔枪口光效的开关终于生效了

`ignoreEnchantedMuzzleFlash` 之前只挡住了网络包里的覆盖值，没管初始值 —— 附魔枪的
`weapon.isEnchanted()` 是 true，所以无论开关怎么设，显示的都是附魔光效。现在开关直接决定初始值。

## 三、JEI 铁砧页：枪和配件都有了

JEI 19 不再自行扫描铁砧，必须由模组主动注册。我们在插件里把每把枪和每个配件都注册了两条：

| 组合 | 产物 |
|---|---|
| 同款 + 同款 | 合并修复 |
| 损坏的 + 维修套件 | 修复 |

遍历的是注册表而不是固定列表，所以附属模组新增的枪和配件自动包含在内。

## 四、物理结构：推力不再按质量缩放

1.0.9 用的是 Sable 的拳击曲线（`punchCurve` + 逆法向质量），这在结构被翻转或倒置时会算错方向，
而且把冲量按质量缩放意味着**每块结构得到的速度变化都一样** —— 大型载具被枪打得像没有重量。

现在改成和 Sable 自己的箭矢命中一致的做法：

```
冲量 = punchScale × 3.0         （固定值，与质量无关）
作用点 = 命中点                  （不是射手位置）
上限   = 质量 × 剩余速度预算      （只作封顶）
                      自旋预算 / 单位自旋
```

结果是：轻结构明显被推动、重载具几乎不动、翻转结构不再乱转。霰弹连发也仍然受速度上限保护。

## 五、射速上限撤销

1.0.9 试过把全局射速下限锁在 2 tick（600 RPM），现在撤销 —— 这件事交给附魔标签就够了，
代码里不必再拦一道。
