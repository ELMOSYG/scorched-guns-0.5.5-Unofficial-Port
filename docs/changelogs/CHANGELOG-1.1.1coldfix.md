# Scorched Guns 1.1.1coldfix (1.21.1 / NeoForge)

## 主要修复：子弹实体堆积

**现象**：世界里会积累大量子弹实体，用 `/tp @e` 能一次拉出上百个，它们多半停在模拟距离的边缘。

**原因**：模拟距离小于渲染距离时，两者之间的区域属于“已加载但不会实体 tick”。弹丸进入那里后
`tick()` 不再执行，寿命判定也就永不推进，于是永久停住；而实体雷达仍能看到它们，看起来像“卡在
区块边缘不掉”。此外这些实体还会被写进区块存档，区块反复加载后越积越多。

**修复（三层）**：
- 弹丸增加了 **125 格**飞行距离上限（8 区块模拟距离正好是 128 格，留 3 格余量），飞满即销毁，
  不再从机制上依赖 chunk 状态。
- 弹丸一旦进入“不会被 tick”的区域就立即销毁，不会停留在边缘。
- 服务端每 10 秒清理一次超出模拟距离的本模组弹丸，处理此前已经滞留的实体。
- 弹丸不再写入区块存档（`shouldBeSaved() = false`），区块卸载不会留下孤儿实体。

## 顺带修复

- **特殊弹药拖尾无色**：139/141 把枪没有 `trail_color` 字段，反序列化把缺失值读成 0（透明黑），
  覆盖了默认颜色。现在缺字段时保留默认色。
- **README / 日志**：换弹系统机制说明见 `docs/reload-system.md`。

## 已知问题（沿用上游行为，未改）

- 逐发装填枪械在换弹期间按“卸载弹药”会导致无限装弹且不消耗弹药；Cowell 等转轮枪可借此凭空刷弹壳。
  规避办法：换弹动画期间不要按卸载键。机制与回退原因见 `docs/reload-system.md`。

## 说明

- 版本号 `1.5.0+1.1.1coldfix`，文件 `scguns-1.1.1coldfix.jar`。
- 仅支持 Minecraft 1.21.1 / NeoForge 21.1.x。
