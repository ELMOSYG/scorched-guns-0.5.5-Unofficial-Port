# Scorched Guns 1.0.7.3

**Minecraft 1.21.1 · NeoForge 21.1.150+**

> 小版本。代码里的版本号仍是 1.0.7，jar 改名为 `1.0.7.3` 便于区分。

两项改动：一项是玩家偏好从服务端配置搬到了客户端，一项是修复弹药抢夺把枪械和盾牌复制成多份的 bug。

## 一、部分配置从服务端移到客户端

这些设置只影响玩家自己看到、听到和手感，却放在服务端配置里——意味着由服务器决定，多人服里各人被同一个值约束，
换服务器还得重新适应。已移到客户端配置 `config/scguns-client.toml`，每个玩家各管各的：

| 配置项 | 内容 |
|---|---|
| `toggleADS` | 开镜是按住还是切换 |
| `alphaOverlay` | 致盲遮罩的透明度 |
| `alphaFadeThreshold` | 遮罩开始淡出的阈值 |
| `soundPercentage` | 失聪时其它音量的百分比 |
| `soundFadeThreshold` | 耳鸣淡出的 tick 数 |
| `ringVolume` | 耳鸣音量 |
| `enableCameraRecoil` | 开火是否推动镜头 |

判断标准只有一条：**只被客户端代码读取的配置就不该由服务端管**。仍然留在服务端的是真正影响玩法或需要两端一致的项，
例如 `enableHeadShots`、`headShotDamageMultiplier`、`gunShotMaxDistance`、`reloadMaxDistance`、`cooldownThreshold`。

> 旧的服务端配置里这些键不再被读取；需要的话在新文件里重新设置，默认值与原来一致。

## 二、弹药抢夺会把枪械和盾牌复制成多份

用吉布斯弹（Gibbs）击杀时，一只守卫会掉落三把枪和三个盾。

原版 0.5.5 的做法是挂 Forge 的 `LootingLevelEvent`，把抢夺等级 +4，然后由战利品表自己的 looting 函数决定哪件物品加多少——
枪和盾所在的条目没有这类函数，所以永远不会被加数量。移植到 1.21.1 时该事件已不存在，代码改成了遍历所有掉落物逐个 `grow()`
加数量，这一改就越界了：枪和盾都是不可堆叠（`stacksTo(1)`），被 `grow(3)` 之后是一个非法堆叠，玩家捡起时游戏把它拆成三份。

修法与抢夺附魔保持一致：

- 不可堆叠的物品（枪、盾、盔甲）**不加数量**
- 可堆叠的物品最多加到堆叠上限，不会越界
- 装了补丁附属（`tepox_scguns_enchantments`）时仍走"提升抢夺等级"的原版路径

## 三、枪械可以打掉怪物手里的盾

原版的破盾只有一种：玩家被拿斧头的生物击中时，`Player#disableShield()` 让盾进 100 tick 冷却。怪物举盾则完全没有对应
机制——`disableShield()` 声明在 `Player` 上，非玩家连物品冷却都不存在，所以一只举盾的骷髅或警卫面对任何攻击都永远
不会掉盾。

枪械的破盾（`handleShieldHit`）之前也只处理玩家，同样跳过了非玩家。现在：

- 任意生物举盾被击中时，按枪械的破盾概率掷骰（火箭 100%、Osborne 90%、MicroJet 75%、等离子 70%、Krahg 60%、
  Beowulf 50%、默认 30%）
- 破盾成功：玩家 ⇒ 盾进 100 tick 冷却；非玩家 ⇒ 盾被击落（它们没有物品冷却，击落是等效结果，且玩家可以捡走）
- 没破盾：照旧格挡，盾 -12 耐久并播放格挡音效

**默认关闭。** 举盾的生物（Guard Villagers 的警卫、被其它模组发了盾的骷髅）通常有自己的盾牌逻辑，直接把盾夺走可能
干扰它们的 AI。开关是 `guns_break_mob_shields`，默认 `false`；需要它的整合包自己打开。即使关闭，格挡仍会消耗盾
耐久，所以这些盾并非无敌。
