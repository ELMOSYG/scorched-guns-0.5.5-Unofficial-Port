# 枪械造价：Scorched Guns 与 TaCZ 的对照调查

> 传闻："scguns 的枪比 tacz 贵"。本调查只比较**普通枪械**（按玩家要求排除 `scorched_blueprint` 那一档毕业武器），
> 数据全部来自本仓库与玩家机器上的 TaCZ 默认枪包，不依赖传闻。

- Scorched Guns：`src/main/resources/data/scguns/recipe/**`（0.5.5 移植版数据）+ 枪械工作台代码
  （`GunBenchMenu`、`GunBenchRecipe`）。
- TaCZ：`D:\MCJAVA\.minecraft\versions\1.20.1-Forge_47.3.22\tacz\tacz_default_gun\data\tacz\recipes\**`
  （默认枪包，tacz 1.1.8）；工作台配方取自 `tacz-1.20.1-1.1.8-hotfix2.jar`。
- 复算工具：`tools/gun_cost_report.py`（`--bom` / `--detail <枪名>` / `--ammo`）。

## 1. 两边的制作机制（这才是"贵"的差别所在）

| | Scorched Guns | TaCZ |
|---|---|---|
| 台子 | 枪械工作台（`scguns:gun_bench`，1 铁 + 2 木板 + 1 燧石） | 枪械制造台（3 原木 + 2 铁 + 1 铁块） |
| 前置机器 | **冲压机**（1 铁块 + 2 铁 + 6 圆石 + 熔炉） | 无 |
| 模具 | **必需**：空白模具（`blank_mold`）= 5 晶碳锭 → 切石成弹头/弹壳/枪械零件模具 | 无 |
| 蓝图 | **必需**：按档位的蓝图（蓝图 - 古典/锈岭/联邦/边疆/COG…；掉落或信物复制；台子里**不消耗**） | 无 |
| 材料 | 铁 + 晶碳（mod 矿石）+ 木板 | 铁/金/钻石/青金石/原木 |
| 零件 | 枪机、枪管、握把、弹匣、枪机框分别制造再组装 | 无零件，直接按材料表出枪 |

### 蓝图不消耗（关键事实）

`GunBenchMenu.consumeIngredients()` 只遍历 `recipe.getModuleIngredients()`（容器槽 0–9 的十个模块位），
把每个减 1；**蓝图在容器槽 11，不在循环里**。所以一张蓝图 = 一个档位的**一次性门票**，
不是每把枪的成本。获取方式：掉落/战利品，或按档位的"复制"配方
（4 蓝图碎片 + 4 纸 + 1 个档位信物，如 `labor_trophy`、`gold_idol`、`redcoat_boots`、`shulker_core`）。

## 4. 弹药（持续开火的成本）

Scorched Guns `standard_copper_round` = 1 中铜弹壳 + 1 火药粉 + 1 弹头：

- 铜壳：1 铜锭 → 10 个 ⇒ **0.1 铜/发**
- 火药粉：1 火药 → 6 份 ⇒ **0.167 火药/发**
- 弹头：`#stan_bullet_tips`，铁粒或 `standard_bullet`（1 铁 → 12 颗）⇒ **0.08–0.11 铁/发**

TaCZ `762x39`：15 铜 + 3 火药 → 35 发 ⇒ **0.43 铜 + 0.086 火药/发**；
`556x45`：15 铜 + 3 火药 → 45 发 ⇒ 更便宜。

⇒ 每发成本同一量级：Scorched Guns 铜便宜约 4 倍、火药贵约 2 倍，另加一点铁；TaCZ 反之。

## 5. 结论

1. **"枪比 TaCZ 贵"在净材料上不成立**：非毕业档的 scguns 每把 3–15 铁（+ 3–11 晶碳），
   而 TaCZ 同角色是 16（手枪）到 320（反器材）铁，中高档还要金/钻石/青金石/下界合金。
   只看金属，TaCZ 普遍是 Scorched Guns 的 **2–20 倍**。
2. **贵在"门票"而不在"每把"**：蓝图（掉落/信物解锁，台里不消耗）、冲压机、
   若干空白模具（每个 5 晶碳）、以及晶碳这种 mod 矿石。第一次搭起来确实要一趟矿+机器，
   但之后每把枪只是 8–15 铁的量级。
3. **弹药同量级**，不存在"scguns 打不起"。
4. 如果传闻来自"毕业武器"或"赤焦档"（`scorched_blueprint`，本次按要求排除），那另当别论 ——
   那一档的入口是信物/掉落，本来就不是按材料计的。

**一句话**：贵的是**进入某个档位的门槛**（蓝图、模具、压机、晶碳），不是枪本身；
把一次性投入摊到每把枪上会显著夸大单枪成本。
